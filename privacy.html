たま屋（以下「提供者」）は、配信ツール「PopAct」（以下「本ソフトウェア」）と販売ページ（popact.github.io）で扱う情報を、次のとおり扱います。

1. パソコンの中に置くもの

本ソフトウェアは、利用者の Windows パソコンの上で動きます。設定（TikTok のユーザー名・ルール・ライセンスキー・Minecraft の RCON や OBS のパスワードなど）、ログ、配信の集計は、そのパソコンの中に保存します。

2. 中継サーバーに送るもの

ウィジェットと通知を OBS や TikTok LIVE Studio に表示するため、提供者の中継サーバー（Cloudflare の上で動いています）を通して、配信画面に出すものを届けます。

  • 送るもの: 視聴者の名前・コメント・ギフトなどの配信の出来事、集計、ウィジェットの設定、利用者がアップロードした音や画像
  • 送らないもの: RCON や OBS のパスワード、ライセンスキーなどの設定（設定が変わったという合図だけを送ります）
  • 中継サーバーには、表示に必要な分だけを保存し、それ以外の目的には使いません。
  • 保存する期間: 配信画面の表示に使う最新の状態（ウィジェットの設定・集計・最近の出来事 40 件まで・ギフトジャーの中身）は、新しい内容で上書きします。最近の出来事は、次の配信が始まったときに消します。利用者がアップロードした音・画像は、利用者から消してほしいと申し出があるまで保存します。「URL を作り直す」をしたあとの前の URL の内容も、申し出があるまで残ります。
  • 通信のしくみ上、接続元の IP アドレスなどは中継サーバーに届きます。動作の記録（ログ）として残すものと期間: 中継サーバーの動作の記録（Cloudflare の Workers Logs）に、受け付けた要求の日時・URL・結果と、エラーの内容を残します。この記録には、接続元の IP アドレスなどの通信の情報が含まれることがあります。記録は Cloudflare によって 7 日以内に消されます。

3. ライセンスの確かめで送るもの

  • 有料プランの契約が続いているかを確かめるため、ライセンスキーそのものではなく、キーから作った識別用の値（ハッシュ）を中継サーバーに送ります。中継サーバーは、決済サービスの Stripe に契約の状態を問い合わせます。
  • 1 つのキーを 1 つの TikTok アカウントに結びつけるため、キーのハッシュと一緒に、つないでいる TikTok のユーザー名を中継サーバーに送ります。中継サーバーは、結びついたユーザー名と付け替えた日時を保存します。この記録は、キーの使い回しを防ぐため、契約が終わったあとも保存します。

4. 購入の情報

  • 購入は Stripe の決済ページで行います。カード番号などのお支払いの情報は Stripe が扱い、本ソフトウェアや提供者がカード番号を受け取ることはありません。
  • 提供者は Stripe の管理画面で、契約の状態や、購入のときに入力されたメールアドレスなどを見ることができます。キーをなくした方への案内などの問い合わせの対応に使います。

5. アプリから問い合わせたときに送るもの

PopAct のヘッダーの「お問い合わせ」から送ったときだけ、次のものを提供者の中継サーバー（Cloudflare の上で動いています）に送ります。送る前に、窓で「一緒に送るもの」と、付けたログの中身を見られます。

  • いつも送るもの: 種類（エラー・キーをなくした・購入と返金・そのほか）、書いた本文、そして次の「一緒に送るもの」です。PopAct の版・配布版かどうか、Windows と Node.js の版、プランの名前、TikTok のユーザー名とつながりの状態、送信の方法、各ゲームとのつながりの状態、中継のつながりの状態。ライセンスキー、中継の合言葉、RCON や OBS のパスワードは送りません。
  • メールアドレス: 「メールでも返事がほしい」を選んだときだけ送ります。選ばなければ、返事は PopAct アプリの中に届きます。
  • ログ: 「ログを付ける」を選んだときだけ、今日と昨日の動作の記録（ログ）を送ります。送るログでは、視聴者の名前（ユーザー名と表示名）を「視聴者1」のような番号に、コメントの本文を「（コメント）」に、パソコンのユーザーのフォルダの名前を「%USERPROFILE%」に置き換えてから送ります（置き換えたログの写しは、パソコンの中に 14 日残して消します）。名前やコメントが 1 文字だけ・数字だけのときは置き換えられません。
  • 添付: 利用者が選んだ画像（PNG・JPEG）と動画（MP4・WebM）を、そのまま送ります。画面の写真や録画に視聴者の名前やコメントが映っていると、そのまま届きます。送る前に、映っていないか確かめてください。
  • 返事: 提供者の返事は中継サーバーに置かれ、PopAct アプリが 10 分ごとに取りに行きます（返事を待っている問い合わせがあるときだけ）。

送られたものは、中継サーバーに保存し、返事と調査のためだけに使います。最後にやり取りがあってから 90 日たつと、添付とログを含めてすべて消します。メールアドレスを書いたときは、提供者がそのアドレスにメールで返事することがあります。

6. TikTok への接続

本ソフトウェアは、配信者のユーザー名を使って TikTok から配信の出来事を受け取ります。ふだんは TikTok のアカウントにログインしません。

視聴者のレベルの見張り（視聴者のギフターレベル・メンバーレベルが上がったことに気づく機能）を使うときだけ、本ソフトウェアの中の TikTok のページで、利用者が自分でログインします。このとき本ソフトウェアは、そのページから TikTok の視聴者の一覧とプロフィールを読み、視聴者の数値の ID・ユーザー名・表示名・レベルだけを取り出して使います（読んだ一覧そのものは保存しません）。ログインの情報はパソコンの中（Microsoft Edge WebView2 の保存場所）に残り、本ソフトウェアが読むことはありません。レベルが上がったという知らせは、ほかの配信の出来事（ギフト・フォローなど）と同じに扱い、配信画面（ウィジェット・通知）に出します。

接続の手続きの一部（接続の署名など）は Euler Stream のサービスを通るため、配信者のユーザー名など接続に要る情報が Euler Stream に届きます。

7. 読み上げの声

  • Edge の声を選ぶと、読み上げる文を Microsoft の音声合成のサービスに送ります。
  • Google 翻訳の声を選ぶと、読み上げる文を Google に送ります。
  • Windows 標準の声・VOICEVOX・COEIROINK は、パソコンの中で声を作ります（外へは送りません）。

8. ダウンロードするもの

次のときは、それぞれの配布元からファイルや情報を取ってきます。ふつうのダウンロードと同じく、接続元の IP アドレスなどは配布元に届きますが、本ソフトウェアから利用者の情報を送ることはありません。

  • 付属のゲーム「たま屋スプリント」の最新の版を確かめるとき・入れるとき（GitHub）
  • ゲームの準備のボタンで MOD などを入れるとき（GitHub・Thunderstore・Chaos Mod のワークショップなど）
  • 素材ライブラリの音や画像を使うとき（提供者の中継サーバー）

9. 販売ページ

  • 販売ページは GitHub Pages で公開しています。ページを開くと、GitHub のサーバーに接続元の IP アドレスなどが届きます。
  • 文字の表示に Google Fonts を読み込んでいるため、ページを開くと Google のサーバーにも接続元の IP アドレスやブラウザーの情報が届きます。
  • 販売ページでは、アクセス解析や広告のためのクッキーは使っていません。

10. ほかの人に渡すこと

提供者は、このポリシーに書いた送り先（中継サーバーを動かす Cloudflare・決済の Stripe など）のほかに、集めた情報をほかの人に渡しません。ただし、法令に基づいて求められたとき、人の命・体・財産を守るために必要で本人の同意を得るのが難しいときは、この限りではありません。

11. 開示・訂正・削除の求め

中継サーバーに保存した内容（音・画像・前の URL の内容など）を消してほしいとき、ライセンスの結びつきについて知りたい・直してほしいときは、popact.support@gmail.com か、アプリの「お問い合わせ」からご連絡ください。ご本人であることを確かめたうえで、遅滞なく対応します。ライセンスの結びつきの記録は、契約が続いている間は消せないことがあります。

12. このポリシーの変更

このポリシーを変えるときは、変える内容と始める日を、販売ページで前もって知らせます。
