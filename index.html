使い始めるまで

3 つの手順で、今日の配信から使えます。

1

ダウンロードして開く

zip を展開して、PopAct.exe を開きます。インストールは要りません。

2

TikTok につなぐ

配信者のユーザー名を入れて接続します。ログインやパスワードは要りません。

3

ルールを作る・OBS に貼る

ギフトで動かすルールを作ったり、ウィジェットの URL を OBS に貼ったりします。テストのボタンで、配信の前に動きを確かめられます。

できること

ギフトで、ゲームの中が変わる

「バラが 5 個届いたらゾンビを 5 体出す」のように、配信で起きたことをきっかけに、ゲームへ命令を送るルールを作れます。

  • きっかけ: ギフト（コイン数の範囲も）・コメントの言葉・いいねの数・フォロー・シェア・入室
  • 送り先: Minecraft のサーバーへはコマンドを直接（RCON）、ほかのゲームへはキー入力や HTTP リクエストで
  • 細かい条件: 対象の人・サブスクやフォロワーなどの属性・クールダウン・1 人あたりの回数

よくある質問

TikTok のパスワードは必要ですか？

いいえ。配信者のユーザー名だけでつながります。TikTok のアカウントにログインすることはありません。

TikTok や Minecraft の公式ツールですか？

いいえ。個人開発の非公式ツールで、TikTok・Mojang・Microsoft とは関係ありません。TikTok Live への接続はコミュニティで広く使われている方式を採用していますが、TikTok 側の仕様変更により一時的に接続できなくなる可能性があります。その際はアップデートで対応します。

TikTok LIVE Studio でも使えますか？

はい。ウィジェットと通知の URL は、開発者の中継サーバーを通した公開 URL なので、OBS のブラウザソースにも、LIVE Studio の「リンク」のソースにも、同じ URL を貼れます。無料版でも使えます。表示にはインターネット接続が必要です。

解約したらどうなりますか？

ライセンスキーが失効し、無料版の機能範囲に戻ります。作成したルールやプリセットの設定データは消えません。

ライセンスは何台まで使えますか？

ご自身の配信用 PC を想定して複数台のアクティベーションに対応しています（台数上限は購入ページに記載）。

返金はできますか？

決済プラットフォーム（Lemon Squeezy）のポリシーに準じます。まず無料版で動作確認いただくことをおすすめします。

まずは無料版から

ずっと無料で使えます。足りなくなったら、その分野のプランを足してください。

プライバシーポリシー（要約）

本ソフトウェアは利用者の PC 上で動作します。ウィジェットと通知を OBS や LIVE Studio に表示するため、それらに出すもの（視聴者の名前・コメント・ギフトなどの出来事、集計、ウィジェットの設定、アップロードした音・画像）を、開発者の中継サーバー（Cloudflare）を通して配信画面に届けます。中継サーバーには表示に必要な分だけを保存し、それ以外の目的には使いません。RCON のパスワードやライセンスキーなどの設定は送信しません。 ライセンス認証のためキー情報のみが決済プラットフォーム（Lemon Squeezy）に送信されます。
